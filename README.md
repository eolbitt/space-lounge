# 혼자지만, 같은 우주에 있는 사람들

작은 우주인이 되어 하나의 넓은 공유 공간을 천천히 유영하는 **침묵의 공존** 웹 MVP입니다.  
채팅도 경쟁도 없습니다. 다른 방문자는 작은 우주인으로만 스쳐 지나갑니다.

## 경험

- 천천히 **드리프트** (WASD / 화살표, Q·E 상승·하강)
- **지구 바라보기**
- 행성을 클릭해 **궤도 유영**
- 다른 우주인과 말없이 스쳐 지남 (모의 프레즌스)

천체(태양·수성~해왕성·달 등)는 아바타 크기의 약 **10배**로 두어, 점이 아닌 읽을 수 있는 천체로 보이게 했습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43127](http://127.0.0.1:43127) 을 엽니다.

## 기술

- Next.js (App Router) · TypeScript · Tailwind CSS
- three.js / React Three Fiber · @react-three/drei
- 실시간 백엔드 없이 **모의 다중 프레즌스** (로컬에서 다른 방문자가 타원 경로로 유영)

## MVP에서 미룬 것

- 실제 WebSocket / 공유 세션
- 계정·아바타 커스터마이즈
- 물리 기반 스케일·궤도 역학
- 사운드스케이프
